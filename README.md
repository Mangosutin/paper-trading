# paper-trading v0.1.0

Windows 向けの仮想株式売買アプリケーションです。実際の証券口座へ接続せず、仮想資金と SQLite を使って日足データ上の売買を試せます。

## 概要

- 日足ローソク足、出来高、SMA25、SMA75 の表示
- 成行注文・指値注文（買い／売り）
- 現金、保有数量、移動平均法による取得単価、評価損益、総資産の表示
- SQLite に口座、注文、約定、ポジション、価格キャッシュ、ウォッチリストを保存
- 約定履歴の CSV 出力（`exports/`）
- ウォッチリストの追加・削除（初期値: `7203.T`, `9984.T`, `AAPL`）

初期仮想資金は `config.yaml` の `account.initial_cash` で設定します。日本株について `trading.enforce_lot: true` の場合、注文数量は100株単位です。

## セットアップ手順

### 必要環境

- Windows 10 / 11
- Python 3.12 以降（インストール時に PATH を有効化）
- インターネット接続（市場データ取得時）

### インストール

1. このフォルダーを任意の場所に展開します。
2. `setup.bat` をダブルクリックします。
3. 仮想環境 `.venv` が作成され、`requirements.txt` のパッケージがインストールされます。
4. 完了後、`run.bat` を実行します。

### 起動

`run.bat` は `.venv` が存在する場合に限り、その Python で `python -m src.main` を実行します。.venv がない場合は `setup.bat` の実行を案内して終了します。

## 使い方

1. 起動すると、ウォッチリストの初期銘柄が表示されます。
2. 左側で銘柄を選ぶと、日足チャートと価格が読み込まれます。
3. 「追加」欄に銘柄コードを入力してウォッチリストへ追加できます。選択銘柄は「選択銘柄を削除」で削除できます。
4. 右側の注文欄で買い／売り、成行／指値、数量を指定して「注文する」を押します。
5. 成行注文は表示取得価格を基準に即時約定します。指値注文は、取得した日足バーの安値・高値が指値に達した場合に約定します。
6. 保有状況、現金、評価損益、総資産は画面下部に表示されます。
7. 「ファイル」→「取引履歴を CSV 出力」で `exports/` に約定履歴を書き出せます。

指値注文は日足 OHLC だけで判定するため、注文後に始まった日足バーを対象にします。注文時刻より前のバーによって約定することはありません。日中の約定時刻や板状況を再現するものではありません。

## 設定

`config.yaml` で次の項目を変更できます。

```yaml
account:
  initial_cash: 1000000

data:
  provider: yfinance
  poll_seconds: 60
  cache_daily: true

trading:
  enforce_lot: true
  fee_model: zero
  slippage_bps: 0

screener:
  enabled: false
```

- `initial_cash`: 新規 DB 作成時の初期仮想資金。既存 DB の現金残高は変更しません。
- `provider`: v0.1.0 では `yfinance` のみ対応します。
- `poll_seconds`: 選択銘柄の画面更新間隔（秒）。
- `cache_daily`: 当日取得した日足を SQLite にキャッシュします。
- `enforce_lot`: `.T` で終わる銘柄の100株単位チェックを有効化します。
- `fee_model`: v0.1.0 では `zero`（手数料0円）のみ対応します。
- `slippage_bps`: 約定価格に適用する不利方向のスリッページ（basis points）。
- `screener.enabled`: v0.1.0 では未使用です。

## データ遅延と yfinance の注意

画面の価格表示には「約15-20分遅延」と取得時刻を併記します。ただし、遅延時間はデータ提供元・市場・契約条件によって異なり、このアプリがリアルタイム性や一定の遅延時間を保証するものではありません。

yfinance は Yahoo Finance の非公式なデータ取得手段です。提供条件、取得可能な期間・間隔、データ内容は変更されることがあります。取得失敗やデータが空の場合はステータスバーに理由を表示し、`logs/app.log` に記録します。通信失敗時は利用可能なキャッシュを表示する場合があります。

v0.1.0 では通貨換算を実装していません。口座現金と銘柄価格は同じ通貨単位として計算されるため、JPY 建て銘柄と USD 建て銘柄（例: `AAPL`）を同時に取引・保有すると、買付余力・評価損益・総資産が通貨換算済みの金額にはなりません。異なる通貨の銘柄を混在させないでください。

このアプリは学習・検証用のペーパートレーディングです。実際の市場価格、注文執行、税金、配当、証券会社の手数料・取引規則を完全に再現しません。実際の投資判断や売買には使用しないでください。

## 保存先

- `data/paper_trading.db`: SQLite データベース
- `logs/app.log`: アプリケーションログ
- `exports/`: CSV 出力先
